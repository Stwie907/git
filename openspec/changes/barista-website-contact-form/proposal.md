## Why

需要一个展示咖啡师/咖啡店品牌的网站，让访客了解店铺信息、咖啡产品和服务内容。同时，访客应能通过联系方式页面提交咨询留言，方便店主收集客户反馈和预约请求。

## What Changes

- 创建一个咖啡师主题静态网站，包含首页、关于我们、咖啡菜单、联系方式等页面。
- 在联系方式页面添加联系表单，收集用户姓名、邮箱和留言内容。
- 实现表单提交后端，将提交的留言数据持久化存储到 JSON 文件中。
- 提供表单提交成功或失败的反馈提示。

## Capabilities

### New Capabilities
- `barista-website`: 咖啡师品牌网站的整体页面结构、导航、首页、关于我们、咖啡菜单和联系方式页面。
- `contact-form`: 联系方式页面的表单组件，包含姓名、邮箱、留言字段，以及后端 JSON 文件持久化存储逻辑。

### Modified Capabilities
- 无

## Impact

- 新增网站前端 HTML/CSS/JS 文件（或项目框架文件）。
- 新增后端脚本处理表单提交并写入 JSON 文件。
- 新增 JSON 数据文件用于存储留言记录。
- 无外部依赖或现有 API 变更。
