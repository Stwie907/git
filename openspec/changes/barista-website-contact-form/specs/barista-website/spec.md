## ADDED Requirements

### Requirement: Website has a homepage
The system SHALL provide a homepage that introduces the barista brand and includes navigation to other pages.

#### Scenario: Visitor opens homepage
- **WHEN** a visitor navigates to `/`
- **THEN** the page displays the barista brand name, a brief tagline, and a navigation menu

### Requirement: Website has an about page
The system SHALL provide an about page that describes the barista or coffee shop.

#### Scenario: Visitor opens about page
- **WHEN** a visitor navigates to `/about.html`
- **THEN** the page displays background information about the barista or shop

### Requirement: Website has a menu page
The system SHALL provide a menu page that lists coffee and related products.

#### Scenario: Visitor opens menu page
- **WHEN** a visitor navigates to `/menu.html`
- **THEN** the page displays a list of coffee items with names and prices

### Requirement: Website has a contact page
The system SHALL provide a contact page that displays contact information and a contact form.

#### Scenario: Visitor opens contact page
- **WHEN** a visitor navigates to `/contact.html`
- **THEN** the page displays the shop contact details and a form for submitting a message

### Requirement: Website navigation is consistent
The system SHALL provide a consistent navigation menu across all pages.

#### Scenario: Visitor switches pages
- **WHEN** a visitor clicks a navigation link on any page
- **THEN** the browser navigates to the corresponding page
